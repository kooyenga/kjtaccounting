## Put it on GitHub Pages

1. Create a free GitHub account if you do not already have one.
2. Click **New repository**.
3. Name it `kjtaccounting`.
4. Make the repository **Public**.
5. Upload all four website files from this folder. The files should be at the top level of the repository, not inside another folder.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose the `main` branch and `/ (root)`, then click **Save**.
9. GitHub will give you a temporary address such as:
   `https://YOUR-USERNAME.github.io/kjtaccounting/`

## Connect KJTAccounting.com

After the GitHub site is working:

1. In the repository go to **Settings → Pages**.
2. Under **Custom domain**, enter `kjtaccounting.com`.
3. GitHub will tell you what DNS records to add with the company where you bought the domain.
4. Add those records at your domain registrar.
5. Return to GitHub Pages and enable **Enforce HTTPS** when it becomes available.

Do not cancel or transfer the domain. You are only changing its DNS so it points to GitHub Pages.

- "Accounting support" is used as the main positioning.
